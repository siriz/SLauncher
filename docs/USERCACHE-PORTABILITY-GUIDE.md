# UserCache 백업 및 이전 가이드

> **이 문서는 더 이상 최신 내용이 아닙니다.** SLauncher는 더 이상 실행 파일 옆의
> `UserCache` 폴더에 사용자 데이터를 저장하지 않으므로, 이 문서에서 설명하던
> "UserCache 폴더를 통째로 복사/백업"하는 방식은 더 이상 그대로 동작하지 않습니다.

## 변경된 내용

설정, 저장된 항목, 탭은 이제 실행 파일 옆이 아니라 사용자별 위치인
`%LOCALAPPDATA%\SLauncher\UserCache`에 저장됩니다. 덕분에 재설치나 업데이트,
재빌드에도 설정이 안전하게 유지되지만, 실행 파일을 복사한다고 해서 데이터가
함께 따라가지는 않습니다.

## 다른 PC로 설정 옮기기

이제는 설정 화면의 **백업 및 복원** 기능을 사용하세요:

1. 원본 PC에서: **설정 → 백업 및 복원 → 내보내기...** 를 눌러
   `.slauncherbackup` 파일로 저장합니다.
2. 그 파일을 옮기려는 PC로 복사합니다.
3. 대상 PC에서: **설정 → 백업 및 복원 → 가져오기...** 를 눌러 해당 파일을
   선택하고, 안내에 따라 SLauncher를 재시작합니다.

내보낸 파일에는 설정, 저장된 항목, 탭 구성이 포함됩니다. 파비콘 캐시는
언제든 다시 만들어지는 캐시일 뿐이라 내보내기 대상에서 제외됩니다.

SLauncher는 여전히 자체 포함(self-contained) 빌드라 별도의 .NET이나
Windows App SDK 설치가 필요 없습니다 - 다만 "데이터가 실행 파일 옆에
있다"는 부분만 더 이상 사실이 아닙니다.
